🔒 Kunci PIN

PIN berfungsi sebagai pengunci layar agar orang lain yang meminjam HP-mu tidak langsung bisa membaca isi jurnal. PIN bukan enkripsi: data tetap tersimpan biasa di penyimpanan browser HP-mu. Aplikasi otomatis terkunci lagi jika ditinggal lebih dari 1 menit.

📦 Cadangan Data

Simpan file cadangan di tempat yang aman (misalnya penyimpanan pribadimu). File ini berisi seluruh jurnal dan tugasmu dalam bentuk teks biasa, jadi jangan dibagikan ke orang lain.

🛡️ Privasi & Penyimpanan

  • Semua data hanya disimpan di browser HP ini. Aplikasi tidak mengirim data ke server mana pun dan tidak memuat apa pun dari internet.
  • Data terikat pada browser yang dipakai. Buka file ini selalu dengan browser yang sama.
  • Jika kamu menghapus data/riwayat browser atau meng-uninstall browser, catatanmu bisa ikut terhapus. Rutinlah mengunduh cadangan.
