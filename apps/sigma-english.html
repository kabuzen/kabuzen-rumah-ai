Tahap 01 · Remembering

Bangun ingatan, lima kata sekali latihan.

Pelajari lima irregular verbs baru setiap hari. Semua kelompok kata dari hari pertama hingga hari ini ditampilkan agar bisa diulang bertahap.

Tandai kata “Belum dikuasai” bila perlu diulang lebih serius. Penanda ini tidak menghapus kewajiban mengulang kata sebelumnya.
Hari belajar dihitung sejak Anda memulai di browser ini.

Gunakan alur sederhana: lihat kata, ucapkan, ingat bentuk lampau, lalu cek makna dan contoh.

Tahap 04 · Analyzing

Periksa gagasan, alasan, dan bukti.

Topik diskusi dengan bacaan pendek dan pertanyaan terpimpin. Bahan di sini bersifat latihan umum, bukan laporan berita terkini.

Bahan diskusi demo disusun untuk latihan berpikir kritis. Verifikasi fakta dan sumber sebelum menjadikan contoh sebagai informasi aktual.

Data perangkat

Backup & aktivitas

Kelola salinan data lokal dan lihat catatan aktivitas dasar. Tidak ada data yang dikirim ke server pada versi ini.

Salinan data

Unduh file JSON untuk cadangan. Impor akan menggabungkan data dan melewati rekaman dengan ID yang sama.

Simpan backup di tempat yang aman. Local storage dapat hilang bila data situs/browser dibersihkan atau perangkat berganti.
Peringatan privasi: jangan masukkan data pribadi sensitif atau rahasia kantor. Aplikasi ini belum memiliki login, enkripsi, kontrol akses, atau sinkronisasi.

Batas MVP ini

Versi awal dirancang untuk memvalidasi alur belajar dan fasilitasi kelompok di satu browser.

  • Luring: aplikasi dan data di browser ini.
  • Daring: materi/sesi dapat disiapkan sebagai agenda lokal, tetapi belum ada ruang bersama real-time.
  • Peserta berbeda perangkat: belum sinkron; memerlukan backend dan autentikasi.
  • Pelafalan: memakai suara perangkat jika tersedia; suara dan kualitas berbeda antar-browser.
  • Progres: dihitung dari aktivitas lokal, bukan sertifikasi kemampuan.
