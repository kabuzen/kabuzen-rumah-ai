Fitur utama

🖱 Rekam setiap klik

Klik kiri dan kanan menjadi satu langkah, lengkap dengan tangkapan layar dan penanda posisi. Pintasan Alt+Shift+R.

✏️ KlikTutor Studio

Sunting judul, penulis, kata pengantar, serta judul dan penjelasan tiap langkah. Ubah urutan atau hapus langkah.

📄 Ekspor PDF

Buku panduan rapi bernomor, siap dibagikan ke tim, murid, atau pelanggan.

🎬 Ekspor MP4

Video dengan gerakan kursor mulus. Landscape 16:9 atau Portrait 9:16 untuk Reels, TikTok, Shorts, dan WhatsApp.

🔊 Suara narasi

Narasi natural lewat Google Cloud Text-to-Speech atau ElevenLabs, memakai kunci API Anda sendiri.

🔒 Data di perangkat

Rekaman dan kunci API hanya disimpan di Chrome perangkat Anda.

Cara memasang

  1. Beli dan terima file
    Klik Beli via WhatsApp. Setelah pembayaran, Anda menerima klik-tutor.zip. Ekstrak file itu (klik kanan → Extract All) sehingga muncul folder klik-tutor.
  2. Buka halaman ekstensi
    Ketik chrome://extensions di bilah alamat Chrome, lalu aktifkan Mode pengembang (Developer mode) di kanan atas.
  3. Muat ekstensi
    Klik Muat yang belum dikemas (Load unpacked), lalu pilih folder klik-tutor hasil ekstrak.
  4. Sematkan ikonnya
    Klik ikon puzzle 🧩 di bilah alat, lalu klik pin di samping KlikTutor.
  5. Mulai merekam
    Buka aplikasi web yang ingin dijelaskan, klik ikon KlikTutor → Mulai Rekaman Baru. Selesai merekam, klik Hentikan dan KlikTutor Studio terbuka otomatis.

Jangan hapus atau pindahkan folder klik-tutor setelah dipasang, karena Chrome memuat ekstensi langsung dari folder itu. Chrome kadang menampilkan peringatan tentang ekstensi mode pengembang; itu wajar untuk ekstensi yang dipasang di luar Chrome Web Store.
