Klinik troubleshooting GolfShop.id

Kasus 1 — Kolom sales_type tidak ditemukan

Gejala: Supabase menampilkan pesan Could not find the 'sales_type' column.

Makna: Kode mengirim nama kolom yang tidak sesuai dengan struktur tabel. Pada pemeriksaan proyek, kolom yang digunakan adalah sales_mode.

Langkah: Buka Supabase → Table Editor → products → periksa nama kolom. Samakan object JavaScript dengan schema aktual. Simpan file, commit, push, lalu uji ulang.

Kasus 2 — Produk tersimpan tetapi tidak muncul di halaman utama

Periksa berurutan: (1) record ada di tabel products; (2) is_active bernilai true; (3) policy SELECT publik mengizinkan produk aktif; (4) index.html membaca Supabase, bukan data contoh localStorage; (5) deployment Vercel memakai commit terbaru; (6) lakukan hard refresh.

Kasus 3 — Gambar tidak muncul

Periksa apakah file sudah ada di bucket product-images, apakah URL publik dapat dibuka langsung, apakah URL tersebut tersimpan pada kolom image_url, dan apakah halaman menggunakan field yang benar.

Kasus 4 — Bucket not found

Pastikan nama bucket tepat product-images dan berada pada project Supabase yang sama dengan Project URL aplikasi. Public bucket hanya mengatur akses baca; pengaturan itu tidak memperbaiki nama bucket yang salah.

Kasus 5 — Vercel Ready tetapi halaman lama

Ready berarti deployment selesai, bukan berarti semua fungsi telah diuji. Cocokkan commit di Vercel dengan GitHub, periksa branch Production, Root Directory, file index.html, domain, lalu lakukan hard refresh.

Kasus 6 — Login berhasil tetapi operasi ditolak

Autentikasi memastikan identitas pengguna. Role dan Row Level Security menentukan izin. Periksa profil, role, policy SELECT/INSERT/UPDATE/DELETE, dan apakah operasi dilakukan oleh akun yang benar.

Evaluasi pemahaman

Pilih satu jawaban untuk setiap pertanyaan, lalu tekan Periksa Jawaban.

Tugas praktik akhir

  1. Buka folder GolfShop.id di VS Code dan identifikasi index.html serta admin.html.
  2. Jalankan git status dan catat hasilnya.
  3. Periksa tabel products di Supabase dan identifikasi kolom image_url serta sales_mode.
  4. Login ke halaman admin, tambahkan satu produk uji dengan gambar.
  5. Periksa file pada Storage dan record pada tabel products.
  6. Buka homepage production dan pastikan produk serta gambar tampil.
  7. Catat bukti screenshot, commit, dan hasil pengujian.
